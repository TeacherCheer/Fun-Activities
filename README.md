# Fun Activities (1) — English Activity Lab ป.6

สื่อฝึกภาษาอังกฤษเรื่องกิจกรรมยามว่าง สำหรับ ป.6 เทอม 2 หน่วยที่ 4 มีคำศัพท์ บทสนทนา แบบฝึกฟัง งานคู่ และแท็บ **★ Hangman** สำหรับทบทวนการสะกดวลี 7 วลี

เปิด `index.html` ในเบราว์เซอร์เพื่อใช้ในเครื่องได้เลย ภาพ โค้ด และเสียงสังเคราะห์ภาษาอังกฤษอยู่ในไฟล์เดียว

## เผยแพร่บน GitHub Pages

1. แตก ZIP และสร้าง repository เช่น `fun-activities-p6` สำหรับ GitHub Free ให้เลือก **Public** หากจะเปิด GitHub Pages
2. ใช้ **Add file → Upload files** แล้วอัปโหลด `index.html`, `README.md` และ `.nojekyll` ไว้ที่ระดับแรกของ repository กด **Commit changes**
3. เปิด **Settings → Pages** และเลือก **Deploy from a branch**
4. เลือก branch ที่มีไฟล์ เช่น **main** และโฟลเดอร์ **/(root)** แล้วกด **Save**
5. เมื่อเผยแพร่เสร็จ กด **Visit site** เพื่อเปิดลิงก์สำหรับนักเรียน

ถ้าหน้าเว็บขึ้น 404 ให้ตรวจว่า `index.html` อยู่ระดับแรกของ branch ที่เลือก
